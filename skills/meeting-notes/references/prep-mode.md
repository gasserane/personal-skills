# 1-1 prep mode

Build the prep sheet for Ane's next recurring manager 1-1 (default counterpart: Lena, biweekly). The prep closes the loop: the previous note's actions and parked items come in, a standing-agenda prep sheet goes out, and after the meeting the prep's topics pre-seed dictation mode.

## Flow

1. **Load state.** Find the latest `Meeting note - Ane-<counterpart> - *.md` and the latest `1-1 prep - ...` in `Ane Plans`. Read the action tables, per-topic Next steps, and Open/parked items. Also scan memory and the current session for status changes since that note.

2. **Status pass, one batched message.** List every action from the last note (Ane's and the counterpart's) with a pre-filled proposed status from what you already know; Ane corrects: done / in progress / blocked / drop. Pre-filling matters: asking twenty open questions wastes her time when the session context already answers half.

3. **Wake the parked items.** Pull every Open/parked entry whose trigger has arrived (date passed, or the gating event happened). Items still dormant stay parked and are not re-listed.

4. **New topics intake, one batched question.** What new items, wins, risks, or asks does she want to raise? Which workstreams are this month's priorities (the agenda caps them at 5)?

5. **Draft the prep sheet in chat** using the standing agenda template below. Ane confirms; then one write to `Ane Plans` as `1-1 prep - Ane-<counterpart> - YYYY-MM-DD.md` (branded `.docx` on request; the prep sheet is usually a personal working document, so `.md` alone often suffices).

## Standing agenda template (agreed with Lena, July 2026)

The prep sheet mirrors the standing agenda, so the meeting can follow it top to bottom. Slot every status, woken parked item, and new topic into exactly one block.

### 1. This month: IPPF EN PLI priority workstreams (max 5)
One subsection per workstream, keeping its stable T-tag. Per workstream, up to four labelled lines: **Progress** (two lines max), **Issues**, **New items / opportunities**, **Reprioritisation / calendar**. The max-5 cap is a forcing function: if more than five candidates emerge, ask Ane which five lead this month and move the rest to Forward planning or the parking lot.

### 2. Forward planning
Three labelled lists: **Upcoming deadlines (next 1-3 months)**, **Critical milestones**, **Travel / workshops / facilitation engagements**. Pull deadlines from the previous note's action tables and from woken parked items; do not re-derive from scratch.

### 3. Cross info sharing (new and PLI-relevant developments)
Two labelled halves: **Global-level PLI aspects (Ane brings)**, pre-filled from her prep input; **MASD-wide, ED Department, cross-department, management (Lena brings)**, left as labelled empty space to capture during the meeting.

### 4. Decisions and support needed
The block the meeting exists for; put the sharpest items here, one entry each, labelled by type: **Trade-off**, **Strategic guidance / recommendation**, **Barrier to remove**, **Sponsorship / authority backup**. Each entry states the decision or steer needed in one sentence, with the two-line context under it. The chase list also lives here: the counterpart's overdue actions from the last note, phrased as asks, not accusations.

### 5. Sustainability of workload (medium / long term)
Raise only when commitments versus capacity have drifted (new parallel workstreams, crunch periods, vacation squeeze). Check every time; write it only when there is something to say. When a workload risk appears in block 1 or 4 (an issue or a trade-off), cross-reference it here rather than repeating it.

### Parking lot
Items that did not make the five, plus anything Ane wants on record but not on the agenda.

## After the meeting

Offer dictation mode for the debrief. The prep sheet's topic list and T-tags carry over, so the interview starts from a known agenda and the new note links cleanly to the old one.
